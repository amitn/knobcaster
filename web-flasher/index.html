Cast Knob — Web Flasher

Flash the firmware to a Waveshare ESP32-S3-Knob over USB, no toolchain required.

  1. Use Chrome or Edge on desktop (WebSerial isn't in Firefox/Safari).
  2. Plug the knob into USB-C.
  3. Click Install and pick the ESP32-S3 port — it's the one named USB JTAG/serial debug unit or USB Serial Device.
    Not the USB-SERIAL CH340 port — this board has a second bridge chip on it, and selecting it gives "board not supported".
  4. Let it flash + erase. (If no S3 port appears: hold BOOT, tap RESET, release BOOT, then retry.)
  5. On first boot it starts a CastKnob-XXXX Wi-Fi AP — join it to set up your network.

After this initial flash, the knob updates itself over the air from GitHub Releases — no cable needed again.
